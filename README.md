# MAZYRA · интерактивный прототип

Учебный пример сквозного процесса: продажи → заявка на образцы → состав и склад → FIFO → производство и задания → выпуск → отгрузка → отзыв → R&D → отдельный заказ.

Это статический HTML/JavaScript-макет для обсуждения требований. Он не является развёрнутым ERPNext или готовой CRM. Реальные письма, списание склада, серверная база и общие пользовательские права не подключены. Количества, партии, цены и длительности вымышлены. Данные сохраняются в localStorage текущего браузера; очистка данных сайта удаляет их.

«Открыть учебный пример» создаёт ОБ-001 на 10 упаковок и отдельный ЗК-001 на 100 упаковок со ссылкой на образцы. Можно открыть любой документ, получить/сохранить отзыв и создать следующий заказ с другим количеством. «Начать заново» сбрасывает только локальный пример после подтверждения.

## Локальный просмотр

```text
python -m http.server 8768 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8768/ . Сайт не требует сборки, зависимостей или базы данных.

## GitHub Pages

Публикуется корень ветки main этого отдельного репозитория. Действующий сайт MAZYRA не изменяется. Публиковать сюда настоящие данные клиентов, пароли и конфигурацию ERPNext нельзя.

## Рабочая система

Предложенное ядро — один ERPNext для продаж, склада и производства. Образцы, связь с последующим заказом, сбор отзыва, передача в R&D и удобное рабочее пространство требуют настройки или доработок. Полный сквозной тест в настоящем ERPNext пока не выполнен. Детальная предварительная оценка — в `erpnext-fit-gap.md`.

## Расширенные рабочие экраны

Добавлены общий дашборд, продажи с показателями дня, производство с килограммами и контрольными точками, закупки рядом с производством, складские минимумы и прогнозы, оценка рейсов доставки, этапы R&D и общая лента задач.

Каждая задача содержит постановщика, исполнителя, дату постановки, срок до минуты (МСК), связанный документ, следующего получателя и историю событий. Есть принятие, выполнение и передача со следующим сроком. История закрытых и будущих задач доступна отдельным переключателем.

Демонстрационный день — 09.11.2026; часы сценария можно менять вручную. При 16:00 точка производства на 13:00 с недостаточным фактом просрочена. Запись нового факта не увеличивает складской остаток. Прогноз и факт разделены. Кнопка выгрузки в производстве создаёт CSV заданий по всем станциям; печать техкарты формирует отдельный лист на станцию.

Подробные требования, определения метрик и границы штатного ERPNext — в [requirements.md](requirements.md). Все новые счётчики, сроки, килограммы и остатки — учебные, не результаты предприятия.
